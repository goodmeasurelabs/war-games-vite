frontend, without implying its retired gameplay backend is available. Editable
vector source is `design/social-card.svg`; rasterize in Chromium at 1200×630,
zero body margin, scale 1. Inspect wide and centered square previews.

body and every runtime asset remain unchanged. The reviewed artifact manifest
allows only the metadata HTML revision and new PNG; builds still verify all bytes.
This focused adoption does not add prerendering, repair gameplay, change analytics,
or claim full SEO adoption, indexing or social-platform cache refresh.
